# Règlement Interne Parking SmartPark (Tunisie)

## Contrôle d'accès
- Toute plaque en blacklist est refusée à l'entrée.
- Les accès conditionnels sont valides entre 06:00 et 22:00 uniquement.
- Les profils VIP sont autorisés en priorité sans facturation standard.
- Les abonnés sont autorisés selon leur contrat.

## Journalisation
- Chaque événement d'entrée et de sortie doit être enregistré avec horodatage.
- Les décisions automatiques doivent conserver un code de règle explicite.

## Explicabilité
- Le personnel doit pouvoir consulter la raison d'un refus/acceptation.
- La règle appliquée doit être affichée dans l'interface.
